# ASA Log Monitor

ARK: Survival Ascendedの画面に表示されるトライブログと参加通知を読み取り、登録したDiscordチャンネルへ届けるWindows x64用アプリです。1台のPC・1つのARK画面を対象に、複数のDiscord送信先を設定できます。

このリポジトリは配布用です。アプリの開発用ソース、Botトークン、個人の設定・履歴・保留データは公開しません。

- [v1.6.3 配布用EXE](https://github.com/kuuaho/asa-log-monitor-releases/releases/download/v1.6.3/ASA_Log_Monitor_v1.6.3_Windows_x64.exe)
- [v1.6.3 ZIP](https://github.com/kuuaho/asa-log-monitor-releases/releases/download/v1.6.3/ASA_Log_Monitor_v1.6.3_Windows_x64.zip)

EXEは付属ファイルをまとめた自己解凍版です。新しい空フォルダーへ展開し、中の`ASA_Log_Monitor.exe`を起動します。ZIPもすべて展開してください。旧版から移る場合は、初回起動前に同梱の「更新手順.txt」を確認してください。

## トークンの保存

初回または変更するときだけ、アプリのトークン欄へ入力して「設定を保存」を押します。保存したトークンは暗号化され、同じPC・Windowsユーザーなら再起動やボタン更新後も利用できます。別PCでは入力し直してください。

v1.6.3では、保存設定を読み込めなかったときに、空の初期設定で元の設定・トークンを上書きすることを防ぎます。読み込み失敗時は元ファイルを保持し、設定リセットが成功するまで上書きを止めます。

通常の設定を読み込めている状態でトークン欄を空にして保存した場合や、「設定を初期値に戻す」を実行した場合はトークンを消去します。新しいトークンはアプリへ入力し、チャットや問い合わせには貼らないでください。

## 更新

v1.6.2以降では「停止」→「アップデート」から確認・取得し、適用の確認後に更新して終了します。完了の案内を待って、同じ場所のアプリを手動で起動し直してください。設定・履歴・保留は保持します。

v1.6.1以前からは、対応版を一度手動で導入します。更新情報の署名と配布物全体を検証し、確認できない更新は適用しません。Windows向けコード署名は未対応のため、SmartScreenが警告する場合があります。

公開サイトの停止や更新情報の期限切れで取得できない場合も、今の版を使い続けられます。

## 主な機能と確認範囲

- トライブログの文字通知、日本時間、順番・送信先別の保留管理
- `/logbot start`による通知先追加、種類別送信先、連続ログのまとめ投稿
- オンライン通知と、停止理由付きのオフライン通知
- 参加バナーの記録、予定メンテナンス、再接続とログ再表示

OCRの誤読や取りこぼしは残り得ます。画面に出なかった記録、完全な参加者名簿・固有ID・正確な退出時刻は取得できません。PCの強制終了・停電・完全な通信断を外部から見守る機能はありません。

v1.6.3の最終ソースの全体試験は2462件、失敗0・エラー0・スキップ3です。公開先からEXE・ZIP・更新ファイルを取得し、検証済みファイルとの一致、更新情報の署名、v1.6.2向けの「更新あり」判定を確認しました。

実GUI・実ゲーム・実Discord投稿・別PCの通し試験は実施していません。詳しい設定は「使い方.txt」、確認範囲は「検証結果.txt」を参照してください。
